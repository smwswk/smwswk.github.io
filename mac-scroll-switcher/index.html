macOS desktop utility

自然滚动设置

一个桌面按钮：检测当前是否有外接鼠标，然后打开 macOS 鼠标或触控板设置页。它不替你切换开关，只把你带到正确位置。

解决的问题

直接改 `com.apple.swipescrolldirection` 有时不会立刻影响真实滚动方向；自动点击系统设置又依赖辅助功能权限和界面结构。这个版本只负责打开对应设置页，最后一步由用户手动操作。

macOS System Settings hidutil 无辅助功能权限

使用方式

  1. 1下载 macOS 包，解压后把 `自然滚动开关.app` 放到桌面或应用程序文件夹。
  2. 2双击它：有外接鼠标时打开“鼠标”，没有外接鼠标时打开“触控板”。
  3. 3在系统设置里手动调整“自然滚动”开关。

开源内容

公开的是 shell 入口脚本、App bundle 模板、构建脚本和 MIT 许可证。源码包不包含个人机器路径，也不依赖私有配置。

设备检测用 `hidutil list` 判断是否存在外接 HID 鼠标。
只打开页面通过 `x-apple.systempreferences` 打开鼠标或触控板设置。
本地构建用普通 App bundle 模板生成 `.app`，不需要辅助功能权限。
