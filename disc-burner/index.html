跨平台
光盘刻录工具

一个旧工作流的公开整理版：Mac 用 hdiutil / drutil，Windows 7 用系统 IMAPI2。目标是把“把文件夹刻成数据光盘”这件小事做成双击入口。

下载 Mac 版 下载 Windows 7 版 查看开源码

Mac 版

Python 3 hdiutil drutil

把 `需要刻录的文件` 生成 ISO，再调用系统刻录工具写入 CD/DVD。脚本目录即工作目录，不依赖个人路径。

下载 Mac 版 查看 burn_disc.py

Windows 7 版

CMD VBScript IMAPI2

不需要 Python，用 Windows 7 自带 IMAPI2 COM 接口直接刻录数据光盘。入口是 `双击刻光盘.cmd`。

下载 Windows 7 版 查看 VBS

开源包内容

公开版只包含脚本、说明、许可证和空的 `需要刻录的文件` 占位目录；真实刻录素材、视频、图片、播放器包和本地绝对路径全部排除。

mac/Python 脚本、双击 `.command`、空素材目录。
windows-win7/`.cmd` 启动器、IMAPI2 `.vbs`、空素材目录。
downloads/Mac 包、Win7 包、完整源码包。

下载完整源码包 GitHub 源码目录

物理刻录仍取决于光驱、空白盘和系统 IMAPI / drutil 状态。这个项目只发布脚本层工作流，不承诺跨所有刻录硬件。
