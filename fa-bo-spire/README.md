# 课间发波 Prototype

一个把童年“攒、挡、波”融合成 roguelike deckbuilder 的静态原型。

## 当前可玩内容

- 半明牌敌人意图：敌人只显示“姿态”和概率提示，读心牌可揭示真实动作。
- 核心结算：攒气、格挡、发波、对波、破防、反弹、吸收、毒波。
- 内容池：30 张卡、10 个遗物、6 个普通敌人、1 个 Boss。
- 杀戮尖塔式地图：7 层分支节点，含普通战、精英战、事件、小卖部、医务室、Boss。
- 开局规则包：北京基础流、天津憋气流、日本寿司流、多人班战流。
- 玩法引导：开局、地图、战斗阶段都会给出下一步动作。
- 战斗辅助：每回合目标、推荐出招、出招预览、HP 条和结算动画。
- 双资源回合：每回合 3 能量，发波还需要额外消耗气。
- 路线经济：胜利给金币，小卖部可以买牌、买遗物、删基础牌。

## 四个规则包

- 北京基础流：母版玩法，攒、防、小波循环，靠读心和破防结束龟缩局。
- 天津憋气流：边攒边挡，初始生命高，适合抗压后用大波翻盘。
- 日本寿司流：攒气像握寿司，高气牌返还资源，适合做资源循环。
- 多人班战流：多段、群波、反弹、换目标，偏混战压制。

## 测试

```bash
npm test
```

测试覆盖当前最关键的设计判断：

- 小波惩罚攒气。
- 格挡化解普通波。
- 必杀破普通防，防止龟缩拖局。
- 半明牌姿态能映射到真实动作。
- 遗物可以改经济，不改卡面文字。
- 地图必须分支并以 Boss 收束。
- 四个地区规则包必须有不同初始构筑和奖励池。
- 推荐出招会根据敌方动作偏向选择波、挡或攒。
- 出招预览会显示预计气、挡、波和战术判断。
- 能量会限制单回合出牌数量。
- 初始跑团会带金币，并在地图中生成小卖部节点。
