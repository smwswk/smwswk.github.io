高德卫星堪景

一个用于拍摄前期侦察的 Skill：先从卫星图寻找视觉异常，再补地址、导出 KML/CSV，必要时对少量候选点做 Google 卫星二次复核。

下载源码包 GitHub 源码 返回首页

适合什么

它不是旅游攻略，也不是景点推荐。目标是找到卫星图上“不一定有名字但可能能拍”的异常结构。

  • 1水系边界、厂区纹理、裸地施工、圆形设施、桥路交汇等视觉候选。
  • 2候选 JSON 转成高德可导入的 KML / CSV，保留理由和地址参照。
  • 3对精选点位做 Google 二次看图，输出联系表、报告和重新排序结果。

公开版清洗

源码包不含真实坐标、账号信息、API key 或堪景结果；默认区域也已改为用户自定义 AOI。

  • 域去掉个人常用城市默认值，只保留“指定区域”工作流。
  • 钥只读取环境变量或通用 Keychain 服务名，不包含任何密钥。
  • 额Google 瓦片抓取必须加 `--confirm-api-fetch`，避免误耗 API 配额。

源码包内容

保留 Skill 说明、AMap 导入文件生成脚本、Google 二筛脚本、agent 配置、README、`.gitignore` 和 MIT 许可。

AMap 导入 `build_amap_import_files.py` 把候选 JSON 转为 KML / CSV。
Google 二筛 `google_satellite_second_pass.py` 只建议复核少量候选点，且需要显式确认抓取。
拍摄边界 高分只代表卫星图异常，不代表现场可进入；工业区只从公共道路外部拍摄。
