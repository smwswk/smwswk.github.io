macOS audio utility

蓝牙音质切换

把蓝牙耳机从 HFP 通话音质拉回 A2DP / AAC 音乐链路：内置麦克风负责输入，蓝牙耳机只负责输出。

下载 macOS 包 下载源码 GitHub 源码

解决的问题

当 macOS 把同一副蓝牙耳机同时设为输入和输出时，系统会切到 HFP / Hands-Free Profile，声音会变闷、采样率下降。这个工具先把默认输入切回内置麦克风，再把默认输出切到目标蓝牙耳机。

HFP -> A2DP AAC CoreAudio SwitchAudioSource

使用方式

  1. 1安装 `SwitchAudioSource`，然后运行源码包里的 `install.sh` 编译 CoreAudio 输入切换 helper。
  2. 2设置 `BLUETOOTH_OUTPUT_NAME` 为耳机名称；默认示例是 OPPO Enco Air5 Pro。
  3. 3运行 `run.sh` 或双击 `double-click-switch.command`。

开源内容

公开的是可复用源码和构建脚本，不包含个人机器上的 `.app` 二进制、签名目录或本地隐藏路径。
