Open Source Tool

电影推荐器

一个本地运行的 Python 小工具：先问观看场景、心情、类型、时长和评分偏好，再从 257 部片库里给出可解释推荐；豆瓣已看记录是可选项。

下载源码包 GitHub 源码 返回首页

适合什么场景

不是流媒体平台那种“继续刷”的推荐，而是当你今晚真的要选一部电影时，快速把当前状态转成筛选条件。

  • 1回答观影时间、设备、注意力、同看对象和心情。
  • 2选择类型、时长、年代和最低豆瓣评分。
  • 3可选接入豆瓣已看记录，自动排除已经看过的片。

公开版包含

Python 3 rich 终端 UI 本地 JSON 片库 规则评分 macOS / Windows 启动脚本

源码包排除了 `.venv`、`run.log`、`__pycache__` 和本地豆瓣缓存，只保留可审计代码、片库和启动脚本。

开源与隐私

豆瓣 Cookie 只用于你本机向豆瓣页面发起请求，不发送给作者服务器。不想碰 Cookie 时，直接在问卷里跳过豆瓣抓取。

源码 `main.py`、问卷、推荐器、片库管理和豆瓣抓取模块都在源码包里。
缓存 `data/douban_*.json` 是本地缓存，已被 `.gitignore` 排除，可随时删除。
