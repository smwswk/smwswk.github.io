双机共享显示器切换包

一台 Win7 老电脑走 VGA，一台 Mac 走 HDMI，共用同一台 TF2416 显示器。Mac 端 DDC/CI 不通后，改由 Win7 端主动发起输入源切换，并用 AutoHotkey 绑定 Win+C。

已验证参数

  • 显示器：TF2416
  • VCP 60 / Input Select 可读写
  • VGA / Win7 = 1
  • HDMI / Mac = 3

快捷键

  • Win+C：在 Win7 和 Mac 之间切换
  • Win+Shift+C：直接切到 Mac
  • Win+Ctrl+C：直接切到 Win7

Win7 启动

解压后运行：

start_win_c_hotkey.bat

需要开机自启时运行：

install_win_c_hotkey_on_startup.bat

开源说明

现成 Win7 工具包保留第三方便携工具，方便旧电脑直接运行；源码包只包含脚本、配置和 MIT 许可，不包含 ControlMyMonitor 或 AutoHotkey 二进制文件。

配置化 `config.bat` 集中放显示器 ID、VGA/HDMI 输入值和工具路径。
可审计 切换、诊断、热键、自启和 watcher 都是普通 bat / ahk 文件。
可移植 默认值是 TF2416 的实测参数，其他 DDC/CI 显示器可先跑诊断再改。
