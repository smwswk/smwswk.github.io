Open Source Codex Skill

额度尾注 Skill

一个很小但实用的 Codex Skill：读取本机 Codex OAuth token，查询 WHAM usage 接口，在最终回复结尾追加一行额度状态。

下载 SKILL.md 下载脚本 查看许可证

显示格式

额度：5h 29%｜周 21%

数据来源

读取 ~/.codex/auth.json 中的 OAuth token，请求 chatgpt.com/backend-api/wham/usage。

默认克制

只显示短尾注；重置时间、错误细节和原始 JSON 只有在追问或接近触顶时展开。

安装

mkdir -p ~/.codex/skills/quota-footer/scripts
curl -fsSL https://ai-independent-builder.onrender.com/quota-footer-skill/SKILL.md -o ~/.codex/skills/quota-footer/SKILL.md
curl -fsSL https://ai-independent-builder.onrender.com/quota-footer-skill/quota_footer.py -o ~/.codex/skills/quota-footer/scripts/quota_footer.py
chmod +x ~/.codex/skills/quota-footer/scripts/quota_footer.py

运行

python3 ~/.codex/skills/quota-footer/scripts/quota_footer.py

边界

  • 只适用于本机已有 Codex 登录态的环境。
  • 不上传对话内容，只请求使用量接口。
  • 接口字段可能变化，脚本失败时应降级为“额度：读取失败”。
