Voice Memos Organizer

用 Python 盘点 macOS 语音备忘录、切片转录、生成标题候选和清理清单。公开版默认走 dry-run 和备份，写库、删除、批量改名都要显式确认。

下载源码包 GitHub 源码 返回首页

能做什么

  • 1读取 Voice Memos 的 `CloudRecordings.db`，生成录音清单和处理 manifest。
  • 2用 `ffmpeg` 切片 `.m4a` / `.qta`，再用 `TeleAI/TeleSpeechASR` 转录。
  • 3生成标题候选、摘要、关键词和低信息录音候选，供人工审查。

公开版保护

这不是一个“点一下全自动清理”的工具。它把危险动作拆成候选、dry-run、备份、显式确认和事后校验。

  • 写`apply` / `apply-db` 必须加 `--confirm-live-write`。
  • 删`delete-candidates` 必须先 dry-run，正式执行还要 `--confirm-delete`。
  • 改导出文件夹批量改名必须加 `--confirm-rename`。

源码包内容

已清理掉缓存和本机产物，只保留 Skill 说明、工作流参考、Python 脚本、公开 README、`.gitignore` 和 MIT 许可。

转录主流程 `process_voice_memos.py` 负责盘点、切片、ASR、摘要和结果导出。
安全写入 数据库写入和删除会先备份，公开版还要求显式确认参数。
可独立使用 `organize_recording_folder.py` 可处理已导出的录音文件夹，不必直接碰 Voice Memos 数据库。
